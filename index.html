Rules

Points per task

Difficulty comes from DeepSWE's public pass rate across ~70 model configurations.

Solve early

Order is by when you submitted (GitHub's time), not when we graded it.

Limits

3 graded submissions in total, across all tasks. Rejected PRs (missing files, wrong task ID) don't count. Your best result on each task counts. At most 10 points in total. Draft PRs are not graded. Each PR is one submission: it is graded once, when you click “Ready for review”, and then closed.

Tasks

Each task pays out to its first four solvers (see Rules). Next is what the next solver earns; dots show payout slots already taken. The grey name under each title is its task ID, the name you give ./start.sh. Click a column to sort, a task to see details.

How a submission gets scored

  1. Solve a task with Claude CodeWork interactively; your Claude Code transcript is part of the submission.
  2. Open a PR in your course repo./finish.sh packages your patch and transcript and pushes a branch; opening its PR submits it. Drafts are never graded: click “Ready for review” to submit one. After grading, the PR is closed; run ./finish.sh again to submit again.
  3. We re-gradeThe patch is applied in a clean container and the held-out tests run. Results appear as a comment on your PR.
  4. Board updatesWithin a few minutes (longer near the deadline, when many students submit). You get 3 graded submissions in total, across all tasks.
